# Helpdesk Home Lab

This repository documents hands-on IT support scenarios I am using to strengthen my troubleshooting, networking, Windows support, and user support skills.

The scenarios are based on realistic entry-level helpdesk problems and include the troubleshooting process, commands used, findings, resolution, and lessons learned.

## Scenarios

- Network connectivity troubleshooting
- DNS troubleshooting
- Windows user access issues
- Active Directory basics
- Software and application support
